Avise is an AI assistant for accountants — it helps them reconcile accounts, generate journal entries, and run reports. Every conversation a real user has with it gets recorded. The AI Trace Viewer lets the team look inside those recordings: find errors, spot patterns, and leave notes for each other.

✈️
Think: airplane black box

After every flight, investigators can replay every instrument reading and every system event. The Trace Viewer does the same for AI conversations — full replay, message by message, with every tool call and every error recorded.

Follow a real action: spotting a broken conversation

You open the Trace List. A row has a red dot — that means at least one AI tool call failed. You click it. Here is what happens:

1
Your click changes the URL

The browser navigates to /trace/abc-123 — the conversation ID becomes part of the address.

2
The server fetches the full conversation

A server function reads every message, every tool call, and every AI response from the database.

3
Messages appear on screen

User messages, AI responses, and tool calls — rendered in order, colour-coded by role (user / assistant / tool).

4
Reviewer notes load alongside

A Notes panel on the right shows comments left by your team — stored in a separate local database so they never touch the original conversation records.

5
You add a note and move on

Your comment is saved instantly and is visible to the whole team — searchable by keyword across all conversations.

The Errors & Reliability tab: where bugs surface

Beyond the main three views, there is a dedicated Errors & Reliability tab. It is the fastest path to understanding what is breaking and why.

❌

Failed Tool Calls

Every tool invocation that returned an error — the tool name, the parameters it was called with, and the error message.

🔁

Loop Detection

A closure signal flags conversations where the AI called the same failing tool twice — a classic stuck-in-a-loop pattern.

📈

Error Trends

Which tools break most often, and is the rate going up or down over time? The answer shapes what the engineering team fixes next.
