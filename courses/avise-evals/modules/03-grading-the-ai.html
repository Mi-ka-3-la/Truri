Grading the AI

Criteria are the individual checks that score one specific thing about the AI's response.

The Grader: What Is a Criterion?

Imagine a checklist a film critic uses after seeing a movie: "Did it have a compelling plot? Were the performances strong? Was the pacing good?" Each item on the list is checked independently and gets its own score. Together they form a picture of quality.

In the evals system, each check on the list is called a Criterion (or a Metric). Each one checks exactly one thing and returns a score from 0 to 1. They are combined to build a full picture of the AI's response quality.

ℹ️
The Score Contract

Every criterion must return a number between 0 and 1 (inclusive). 1 = fully passed. 0 = fully failed. Values in between represent partial success. This consistency is what allows scores to be averaged, combined, and compared.

Check #1: Did the AI Say the Right Thing?

The most common check is StringMatch — it looks at the AI's final text response and asks: does it contain (or start with, or exactly equal) a specific string?

CODE 

new StringMatch(
  "Acme Corp",
  {
    type: "contains",
    caseInsensitive: true,
  }
)
PLAIN ENGLISH

Create a new StringMatch check that looks for a specific vendor name.

We are looking for "Acme Corp" somewhere inside the AI response...

...using a "contains" match (not an exact match of the whole response).

Case-insensitive means "acme corp", "ACME CORP", and "Acme Corp" all count as a match.

Result: 1 if the response contains "Acme Corp", 0 if it does not.

exact The full response must equal the expected string exactly
contains The expected string must appear somewhere in the response (most common)
starts-with The response must begin with the expected string
ends-with The response must end with the expected string

Check #2: Did the AI Produce the Right Output?

Sometimes the AI does more than respond in text — it produces a structured artifact. For example, when you ask it to create a monthly schedule, it produces a propose_schedule artifact with all the schedule parameters (dates, accounts, amounts) ready for the system to use.

ArtifactsExist checks that the AI created exactly the right artifact types — no more, no less.

CODE 

new ArtifactsExist([
  "propose_schedule"
])
PLAIN ENGLISH

Check that the AI created exactly one artifact of type "propose_schedule".

Score 1 if the propose_schedule artifact exists AND no unexpected artifacts were created.

Score 0 if the artifact is missing, or if the AI also created other unexpected artifacts.

This catches cases where the AI creates an artifact when it should not, or fails to create one when it should.

Check #3: Are the Artifact's Values Correct?

Knowing an artifact exists is not enough. You also need to verify its contents. ArtifactPropertyMatch uses JSONPath expressions to extract specific fields from the artifact and compare them to expected values.

CODE 

new ArtifactPropertyMatch(
  "propose_schedule",
  {
    "$.termStart": "2025-01-01",
    "$.termEnd":   "2025-12-31",
    "$.totalAmount": 12000,
  }
)
PLAIN ENGLISH

Look at the "propose_schedule" artifact the AI created.

Check that its termStart field is exactly "2025-01-01" (the schedule must start January 1st).

Check that its termEnd field is exactly "2025-12-31" (must end December 31st).

Check that totalAmount is exactly 12000 dollars.

Score 1 only if ALL three properties match. Score 0 if any one is wrong.

Checks #4 & #5: Did the AI Use the Right Tools?

The AI agent uses tools to do its work (look up data, create schedules, etc.). Two more criteria check the tooling behavior:

🔧
ToolCallsExist

Verifies the AI called specific tools. e.g., it MUST call both findAccounts AND proposeSchedule — if it skips one, score is 0.

🔬
ValidateArtifact

Runs a custom JavaScript function against the artifact data. Use this for complex checks that cannot be expressed as a simple property match (e.g., verifying debits equal credits within 0.01).

🆔
Arbitrary (shouldNotContainLowLevelIds)

A fully custom criterion — scans the AI response for UUIDs or CUIDs and returns 0 if any are found. The AI should never expose raw database IDs to users.
