The Runner: Evalite

Evalite is the engine that powers everything. It integrates with Vitest and provides a local UI to browse results during development. When you run pnpm evals:watch, it re-runs evals whenever files change — like a live coding environment, but for AI quality.

CODE 

// evalite.config.ts
import { defineConfig }
  from "evalite";

export default defineConfig({
  include: [
    "evals/**/*.eval.ts"
  ],
});
PLAIN ENGLISH

This is the configuration file that tells Evalite where to find eval files.

It looks for all files matching the pattern "*.eval.ts" inside the evals/ folder.

Every file with that suffix is an eval file — Evalite will discover and run it automatically.

The naming convention *.eval.ts makes eval files easy to identify at a glance.

Sharing Results: Export to S3

Evalite stores results in a local SQLite database file (evalite.db). But that file lives on your laptop — nobody else can see it. The export script solves this.

Running pnpm evals automatically calls scripts/exportEvaliteToS3.ts after the evals complete. This script reads the evalite output, packages it as a static HTML bundle, and uploads it to S3 under a timestamped folder.

⏱️
Timestamped folders

Each run is stored as a separate folder in S3: 2025-05-14T10:30:00Z/. This preserves the full history so you can compare runs over time.

📦
Static HTML bundle

Evalite exports its UI as a self-contained HTML app. The export script uploads this bundle to S3 so the viewer can serve it inside an iframe.

🔐
AWS IAM authentication

The script uses the AWS SDK with IAM credentials. Only developers with the right AWS permissions can upload new results — keeping the history trustworthy.

Reading Runs from S3

The listRuns() function in services/s3.ts is what populates the sidebar. It asks S3 to list all top-level "prefixes" — each one is a timestamped folder representing one eval run.

CODE 

async function listRuns(): Promise<string[]> {
  const response = await Aws.s3.send(
    new ListObjectsV2Command({
      Bucket: config.evals.s3Bucket,
      Delimiter: "/",
    })
  );

  const runs = response.CommonPrefixes
    ?.map(p => p.Prefix.replace(/\/$/, ""))
    ?? [];

  return runs.sort().reverse();
}
PLAIN ENGLISH

Define an async function that returns a list of run IDs from S3.

Ask S3 to list all objects in the evals bucket, but use "/" as a delimiter — this groups objects by folder instead of listing every file.

S3 returns "CommonPrefixes" — each one is a folder name (e.g. "2025-05-14T10:30:00Z/").

Strip the trailing "/" from each folder name to get the clean run ID.

Sort in reverse order so the most recent runs appear first in the sidebar.

The Clever Iframe Trick

The evalite UI is already a polished, self-contained web app. Rather than rebuilding it from scratch, avise-evals-viewer simply loads it inside an iframe. The assets route on the server proxies files from S3 to the browser, so the iframe can load the full evalite UI as if it were a local page.

💡
Proxy = No CORS Problems

The browser cannot fetch files from S3 directly due to CORS security restrictions. The Next.js server acts as a middleman: it fetches from S3 server-side and forwards the response to the browser. This pattern — server-side proxying — is a common solution for securely loading content from external storage.

You Now Understand the Full Picture

From a natural-language prompt to a score on a shared dashboard — you have traced the entire evals pipeline. Here is a summary of what you have learned:

1
Why evals exist

AI is non-deterministic. You cannot test it with regular unit tests. Evals run real interactions and score them automatically.

2
How the stage is set

EvalsContext loads real data from the database. EvalJournalEntry lazily resolves account data. AccountCache saves redundant DB calls.

3
How individual grades work

StringMatch checks text, ArtifactsExist checks output type, ArtifactPropertyMatch checks field values, ToolCallsExist checks tool usage.

4
How grades are combined

And requires all, Or needs one, AverageScores gives partial credit, Predicate adds conditional logic.

5
How results reach the team

Evalite runs locally → export script uploads to S3 → avise-evals-viewer proxies and displays results via an iframe.
