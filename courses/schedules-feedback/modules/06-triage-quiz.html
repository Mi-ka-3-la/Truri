Triage Quiz

Six real-world scenarios — one per theme. Can you identify the theme, the file, and the change type without looking back?

Scenarios 1–3

Read each scenario and select the best answer. Each question is worth one theme.

Scenario 1 — Cellino: “I need to filter the Prepared Schedules list by Vendor AND by Class AND by expense account at the same time. Right now I can only filter by one dimension.”

Scenario 2 — Bleecker: “In the app I can see which Vendor each schedule belongs to. But every time I export to Excel, the Vendor column isn’t there. Our finance team works out of Excel so this is blocking us.”

Scenario 3 — Flueid’s Peter: “Every month I add 12 entries to a schedule. I name them Amortization 1, Amortization 2 … Amortization 12. I type every single one. Can the system just count for me?”

Scenarios 4–6

Three more scenarios — the trickier ones.

Scenario 4 — J Cummins: “I archived an entry on a schedule, but the schedule still shows it as pending. I thought archiving would remove it.” (The entry was posted when the period was open; the period is now inactive.)

Scenario 5 — Bleecker: “When I’m creating a schedule for a bigger client, the source transaction section keeps jumping up and down. It shows a loading spinner over and over even after I’m done selecting transactions.”

Scenario 6 — Finstrat: “We found two separate 'Rivet Industries' company records in our account. We discovered this while looking at our Leasehold Improvement A/D schedules.” The team fixed it manually with SQL. What should happen next?

Your Schedules triage reference card

You’ve completed the course. Use this cheat sheet next time a Schedules ticket lands in your queue.

A “I need more columns / better filtering in the list” → usePreparedSchedulesPageFilterSet.ts + PreparedSchedulesTable.tsx · LOW–MEDIUM
B “The export is missing my dimension/vendor data” → preparedSchedulesReportService.ts + utils.ts · MEDIUM
C “I have to manually type Description 1, 2, 3…” → helpers.ts + CreateSchedulePageV2 · HIGH
D “Entry still shows pending after I archived it” → PreparedSchedulePage.tsx (UX messaging) · CHORE
E “Source transactions section keeps reloading / bouncing” → EditPreparedScheduleDetailsPage.tsx (debounce sourceIds) · HIGHEST
F “Duplicate company records in schedules” → company import / creation logic · HIGHEST (spike needed)
What to do with every new Schedules complaint

1) Match it to a theme. 2) Find the file. 3) Label the change type (bug/feature/chore/architectural). 4) Estimate complexity (small/medium/large). That’s everything engineering needs to triage and size the story.
