04

Threshold Settings

Settings → Task Accruals → Flux Threshold controls three completely separate things. Understanding which is which avoids a lot of confusion.

One settings panel. Three independent systems.

When you open Settings → Task Accruals → Flux Threshold for Auto-Review, you see three fields. People assume they all work together. They don't — each one controls a completely different part of the system:

% Change Threshold

Controls whether the yellow alert icon appears on the % Change column AND whether auto-review checks the percentage.

fluxPercentChangeThreshold — nullable, no default

$ Change Threshold

Controls whether the yellow alert icon appears on the $ Change column AND whether auto-review checks the dollar amount.

fluxBalanceChangeThreshold — nullable, no default

Days Before End of Period

Controls when flux tasks are created — how many days before the period ends do recurring flux tasks get auto-generated.

fluxDaysBeforePeriodEnd — default: 10
% column value, alert icon, and task creation are three independent systems

The % Change column always shows the calculated number — no setting affects it. The alert icon only appears if a threshold is set AND the create-mom-flux-task feature flag is on AND the comparison is Month over Month. Auto-review runs on its own schedule, separate from display. These three systems share the same settings input but execute independently.

The exact rules for the yellow alert icon

The alert icon (a yellow warning triangle) is the most visible consequence of threshold settings. Here is the complete list of conditions that must ALL be true for it to appear:

1
The create-mom-flux-task feature flag must be ON

If this flag is off (the current default), no alert icon ever appears — regardless of any settings.

2
Comparison must be Month over Month

Alert icons are hardcoded to only appear for the monthOverMonth comparison. QoQ and YoY never show alerts.

3
The relevant threshold must be set (non-null) in Settings

If % Change Threshold is null, the accountPercentChangeOverThreshold flag is never set by the backend. Same for $ Change Threshold.

4
The account's value must exceed the threshold (strictly >, not ≥)

The comparison is Math.abs(value) > threshold. An account exactly at the threshold does NOT trigger the alert.

5
“Hide Threshold Alerts” filter must be OFF

The filter bar has an option to hide alerts. If enabled, icons are suppressed in the UI even if all other conditions are met.

Empty Settings: what still happens vs what goes silent

Both fluxPercentChangeThreshold and fluxBalanceChangeThreshold have no database default — new companies get null. Here's the full impact:

% Change column value Always works. The formula runs on raw balances. Settings do not affect the number displayed.
Yellow alert icon Never appears. With null thresholds, the backend never sets the flag, so the icon has nothing to read.
Auto-review Off completely. If both thresholds are null, isAutoReviewFluxEnabled() returns false and the checker exits immediately.
Task creation timing Uses default: 10 days. fluxDaysBeforePeriodEnd has @default(10) in the database schema. Every new company gets 10 days silently.
The one hidden default: 10 days before period end

This is the only predefined rule that runs even when Settings is completely empty. The fluxDaysBeforePeriodEnd field in the database has @default(10), so flux recurring tasks are created 10 days before the period ends from day one — without the admin configuring anything. It lives in avise-domains/prisma/schema.prisma, line 242.
