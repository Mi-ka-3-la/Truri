Concepte de bază
Commit salvare
O salvare cu mesaj. Înregistrează ce s-a schimbat, cine și când. Nu se șterge niciodată din istoricul proiectului.
Branch copie
O linie paralelă de dezvoltare. Lucrezi în siguranță fără să atingi codul stabil. Se șterge după merge.
Tag bookmark
Un bookmark permanent pe un commit. Marchează o versiune. Nu se mișcă niciodată după creare.
Main producție
Branch-ul principal. Codul care merge în producție. Mereu stabil, mereu testat, protejat de PR-uri.
Pull Request review
Cererea oficială de a merge branch-ul tău în main. Colegii văd exact ce ai schimbat și aprobă sau cer modificări.
Merge combinare
Combinarea unui branch aprobat în main. Codul intră în producție. Branch-ul se șterge după.

Major
Ceva se strică pentru utilizatorii existenți
Codul lor nu mai funcționează după update fără modificări de pe partea lor.
1.4.2 → 2.0.0  # ai redenumit getUser() → fetchUser()
Regula reset: 1.4.2 → 2.0.0, nu 2.4.2
X
Minor
Funcționalitate nouă, nimic nu se strică
Poți upgrada fără să schimbi nimic în codul tău.
1.4.2 → 1.5.0  # ai adăugat export CSV
Regula reset: 1.4.2 → 1.5.0, nu 1.5.2
X
Patch
Bug fix, nimic nou, complet sigur
Repari ceva stricat. Safe de auto-updatat. Hotfix-ul produce aproape mereu un patch.
1.4.2 → 1.4.3  # ai reparat crash la login
4
Taguri și Hotfix
Lightweight tag
Simplu bookmark. Fără mesaj sau autor.
git tag v1.0.0
Annotated tag ✓
Are mesaj, autor, dată. Recomandat pentru release-uri.
git tag -a v1.0.0 -m "Release"
⚠ Tagurile nu se push automat! Trebuie explicit:
git push origin v1.0.0   # un tag
git push origin --tags   # toate
Pre-release stages — ordine strictă:

Hotfix vs patch:
Hotfix = urgență
Branchez din tag-ul live, nu din main. Main are work in progress.
Patch = tipul schimbării
Aproape orice hotfix produce un patch bump: 1.2.9 → 1.2.10
0.x.x = încă figuring it out. Orice poate schimba oricând.
1.0.0 = prima versiune stabilă cu promisiuni.
Nu există limită: 1.30.1 este complet valid.
5
Breaking changes și Changelog
Schimbare Breaking? Bump
Redenumești / ștergi o funcție Da ✕ major
Schimbi ce returnează un endpoint Da ✕ major
Schimbi URL-ul unui endpoint Da ✕ major
Adaugi câmp nou în response Nu ✓ minor
Adaugi endpoint nou Nu ✓ minor
Faci un parametru opțional Nu ✓ minor
Repari un bug fără schimbări API Nu ✓ patch
Format changelog (keepachangelog.com):
## [1.3.0] - 2024-03-13
### Added
 - Export CSV pentru rapoarte
### Changed
 - Buton logout mutat în meniu profil
### Fixed
 - Crash la login pe iOS 16
### Removed
 - Suport Internet Explorer 11
✓ Scris pentru utilizator, nu pentru developer — fără detalii interne de cod
✓ O linie per schimbare, clară și simplă
✓ Breaking changes — mereu separate și cu instrucțiuni clare
✓ Updatat la fiecare release, nu retroactiv
✕ Nu copia commit messages direct — sunt pentru developeri, nu utilizatori
⚡
Regula de aur: Dacă cineva updatează fără să citească nimic și codul lor se strică → MAJOR · Dacă adaugi ceva nou fără să strici nimic → MINOR · Dacă repari ceva → PATCH
