Design System

The single source of truth for Avise's visual language, component library, and implementation guidelines. Built for accounting and close management software — precise, trustworthy, and clean.

Brand Principles
These principles guide every design decision — from a button label to an entire screen layout.
Precise
Every number matters. Financial data is displayed with full fidelity — monospace type, parentheses for negatives, no rounding.
Clear
Hierarchy is never ambiguous. Color, weight, and size work together to direct attention to what matters most on every screen.
Trustworthy
CFOs and controllers trust Avise with sensitive data. The design must feel serious, stable, and reliable — not flashy.
