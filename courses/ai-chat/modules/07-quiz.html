Your AI Chat cheat sheet

Add a toolCreate a file in ai/tools/, add it to ai/tools/index.ts. Implement executor with authorization check. Add as stub if it has many params.
Change the system promptEdit ai/prompts.ts. Test that linking rules, table rules, and topic restrictions still hold. Changes affect all future conversations immediately.
Debug slow responsesCheck: (1) is it a stub round-trip? (2) is it a slow tool query? (3) is the conversation too long? Each has a different fix.
Add a new artifact typeAdd an artifact renderer in AiChatItem/artifacts/. Add the action handler in useArtifactActionsMutation. Create a tool that calls createArtifact() with the new type.
Switch provider for testingPass { overrides: { model: 'openrouter/...' } } in the request body. sanitizeOverrides() must allow the model name — check the allowlist.
Gate a tool behind a flagFollow the proposeMultiLineSchedule pattern in ai/index.ts: if (!flagEnabled('your-flag')) { delete availableTools.yourTool; }
Every AI Chat issue maps to one of seven layers

Frontend rendering → Controller → Conversation loop → Provider → Tool registry → Tool executor → Database. Once you know which layer owns the problem, you know which file to open.
