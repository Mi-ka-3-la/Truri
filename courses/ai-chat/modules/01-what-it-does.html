What Avise AI Chat Does

Before any code — what the user experiences, and why it is genuinely hard to build correctly.

An accounting assistant that can read your books

Ask in plain English

Users type questions like “What did we spend on software in Q3?” and get answers grounded in their actual GL data.

Propose new transactions

The AI can draft journal entries, prepared schedules, and chart-of-accounts additions — all editable before posting.

Analyse uploaded files

Users can attach Excel, PDF, CSV, or image files. The AI reads the content and incorporates it directly into its analysis.

Think: a junior accountant who has read every journal entry in your database

The AI doesn’t guess balances — it calls real API tools that fetch live data, then reasons over the results. If it doesn’t know something, it says so.

Artifacts — richer outputs than plain text

Some AI outputs are interactive UI cards called Artifacts. The AI cannot output Markdown tables — it must use the displayArtifactTable tool instead.

Table Artifact

The displayArtifactTable tool creates a formatted, typed table. Columns can be currency, date, number, or markdown. This replaces Markdown tables entirely.

Journal Entry Artifact

proposeJournalEntry creates a draft JE card with debit/credit lines visible. The user can edit any line and then post directly to the GL.

Schedule Artifact

proposeSchedule and proposeMultiLineSchedule show a full monthly entry preview before the schedule is created.

Accounts Artifact

suggestAccounts builds an editable table of proposed chart-of-accounts entries the user can accept or modify before creation.
